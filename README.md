# CatDog_classification

基于 **PyTorch + VGG16 + BatchNorm** 实现的猫狗二分类图像识别项目。

本项目从自定义 `Dataset` 和 `DataLoader` 开始，实现了数据预处理、数据增强、模型训练、验证、测试、混淆矩阵分析以及单张图片预测等完整流程。

---

## 1. 项目简介

本项目使用猫狗图像数据集进行二分类任务：

- `0`：Cat
- `1`：Dog

项目主要目的是学习和实践 PyTorch 深度学习图像分类流程，包括：

- 自定义 Dataset
- DataLoader
- 数据集划分
- 数据增强
- VGG16 网络
- Batch Normalization
- GPU 加速
- 模型训练与验证
- 学习率调整
- Early Stopping
- 模型保存与加载
- 测试集评估
- 混淆矩阵
- 单张图片预测

## 4. 数据预处理

在进入模型之前，对图片进行统一处理。

主要包括：

- 图片尺寸调整
- Tensor 转换
- 数据归一化
- 训练阶段的数据增强

训练数据使用数据增强，以提高模型的泛化能力并降低过拟合风险。

数据增强可以让模型看到不同角度、不同位置和不同外观的猫狗图片，从而减少模型对训练图片具体细节的依赖。

## 6. 模型

本项目使用：

> **VGG16 + Batch Normalization**

VGG16 是经典卷积神经网络结构，通过连续的卷积层和池化层逐渐提取图像特征。

基本结构：

```text
Input Image
     ↓
Conv
     ↓
BatchNorm
     ↓
ReLU
     ↓
Conv
     ↓
BatchNorm
     ↓
ReLU
     ↓
MaxPool
     ↓
……
     ↓
Fully Connected
     ↓
Binary Classification
```

### 为什么加入 BatchNorm？

Batch Normalization 可以帮助：

- 稳定训练过程
- 加快收敛
- 减少内部数据分布变化
- 在一定程度上缓解过拟合
- 提高训练稳定性

## 7. 损失函数

本项目使用交叉熵损失：

```python
nn.CrossEntropyLoss()
```

用于衡量模型预测结果与真实标签之间的差异。

损失越低，通常说明模型预测结果越接近真实标签。

## 8. 优化器

训练过程中使用优化器更新模型参数。

初始学习率：

```text
0.001
```

学习率会随着训练过程逐渐下降，使模型在训练后期进行更加细致的参数调整。

## 10. Early Stopping

为了避免模型在验证集上的表现长期不再提升，训练过程中加入了 Early Stopping。

设置：

```text
patience = 5
```

也就是说：

> 如果验证集准确率连续 5 个 Epoch 没有提升，则停止训练。

最终训练在第 45 个 Epoch 结束。

# 18. 最差 Batch 分析

在训练过程中还对 Batch 的表现进行了分析。

例如部分表现较差的 Batch：

```text
====================================
最差的 10 个 Batch
====================================
Batch  58 | Accuracy: 76.56% | Loss: 0.4188
Batch  45 | Accuracy: 81.25% | Loss: 0.4107
Batch   4 | Accuracy: 82.81% | Loss: 0.3344
Batch  21 | Accuracy: 82.81% | Loss: 0.3290
```

单个 Batch 的准确率较低并不一定意味着代码出现问题。

原因可能包括：

- 图片本身比较难分类
- 猫狗外观相似
- 图片存在遮挡
- 图片角度特殊
- 光照条件复杂
- 背景干扰
- 图片质量较低

因此不能仅仅根据某一个 Batch 的表现判断整个模型。

更应该关注：

```text
训练集整体表现
验证集整体表现
测试集整体表现
混淆矩阵
```

# 20. 为什么最终选择 Epoch 40？

虽然训练一直进行到 Epoch 45，但 Epoch 40 的验证集准确率最高：

```text
Epoch 40：84.129%
```

之后：

```text
Epoch 41：83.462%
Epoch 42：82.955%
Epoch 43：83.382%
Epoch 44：83.782%
Epoch 45：83.942%
```

虽然 Epoch 45 的准确率已经有所恢复，但仍然没有超过 Epoch 40。

因此：

```text
Epoch 40 → 最佳模型
```

而不是：

```text
Epoch 45 → 最终模型
```

这就是 Early Stopping 和 Best Model Checkpoint 的意义。

# 22. 模型保存

训练过程中，如果验证集准确率得到提升，就保存当前模型：

```text
vgg16_bn_best.pth
```

保存逻辑的核心思想：

```text
验证集准确率提升
        ↓
保存模型
        ↓
继续训练
        ↓
如果之后没有超过
        ↓
仍然保留之前的最佳模型
```

这样可以避免最后一个 Epoch 的模型表现不如最佳模型。

# 27. 后续可以改进的方向

当前模型测试集准确率约为：

```text
84.164%
```

如果希望进一步提高准确率，可以尝试：

### 1. 使用预训练模型

例如：

- ResNet
- EfficientNet
- MobileNet
- ConvNeXt

使用 ImageNet 预训练权重进行迁移学习，通常比从头训练更容易获得较好的效果。

### 2. 调整数据增强

可以尝试：

- RandomCrop
- RandomHorizontalFlip
- RandomRotation
- ColorJitter
- RandomResizedCrop

但数据增强不能过强，否则可能破坏图片中的关键特征。

### 3. 调整 Batch Size

根据 GPU 显存情况尝试：

```text
32
64
128
```

观察训练速度和模型效果。

### 4. 调整学习率

可以进一步尝试：

```text
1e-3
5e-4
1e-4
5e-5
```

寻找更加合适的学习率。

### 5. 使用更合适的学习率调度器

例如：

```text
StepLR
CosineAnnealingLR
ReduceLROnPlateau
OneCycleLR
```

### 6. 进一步分析错误图片

结合混淆矩阵，找出：

```text
猫 → 狗
狗 → 猫
```

中的错误样本。

分析这些图片为什么难以分类，可以帮助进一步优化数据和模型。
